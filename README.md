## Problem 2.15: Accounting Agent

### Submission Instructions

1. **Install the Aintropy Grader Bot**
   - Install the [Aintropy Grader Bot GitHub App](https://github.com/apps/aintropy-grader-bot).
   - Grant it access to your fork so the submission can be evaluated.

2. **Code Organization**
   - All implementation code must be under `src/`.
   - Keep the project organized and executable.

3. **Documentation**
   - All write-ups and supporting documentation must be under `docs/`.
   - Markdown, slides, notebooks, and other formats are accepted.

4. **Execution Instructions**
   - Provide a root-level `run.yaml` containing the exact setup and execution commands.
   - The evaluator executes these commands exactly as written.
   - Ensure the commands work in a clean environment.

5. **GitHub Submission**
   - Push the completed implementation to the default branch of your own fork.
   - No pull request is required.
   - Commits pushed after the test deadline will not be considered.

### Important Notes

- The submission must be completed within the time limit specified in the invitation email.
- The grader must have access to the repository.
- The code, documentation, and `run.yaml` must all be committed.
